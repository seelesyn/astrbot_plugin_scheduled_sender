# astrbot_plugin_scheduled_sender 定时消息轮播

让 Bot 在指定时间向指定会话发送预设的文本消息。支持定时重复(每天 / 每周星期几 / 固定间隔 / cron / 一次性),并且一个任务可以配置多条不同消息,触发时按顺序**轮换发送**。

## 功能特性

- ⏰ 多种时间规则:
  - `08:30` / `每天@21:00` — 每天固定时刻
  - `周一三五@08:30` / `工作日@09:00` / `周末@11:30` — 按星期重复
  - `每30分钟` / `每2小时` — 固定间隔重复
  - `cron 0 8 * * *` — 标准 5 段 cron 表达式(分 时 日 月 周)
  - `2026-10-01 09:00` — 一次性定时,发送后自动删除
- 🔁 多条消息轮换:任务里用 `|` 分隔多条消息,每次触发发一条,循环轮换,轮换进度持久化
- 💾 任务持久化到 `data/plugin_data/astrbot_plugin_scheduled_sender/tasks.json`,重启自动恢复
- 🕐 支持配置时区(默认 `Asia/Shanghai`),错过触发点可配置补发宽限期
- 🔒 可配置仅管理员管理;管理员可跨会话查看/管理全部任务

## 安装

把本目录放进 AstrBot 的 `data/plugins/` 下(或通过 WebUI「插件市场 → 从仓库安装」安装你的仓库),然后在插件页重载即可。依赖 `apscheduler` 会通过 `requirements.txt` 自动安装。

要求 AstrBot v3.5+(建议使用最新版)。

## 使用

所有指令以 `/定时` 开头(别名 `/定时消息`、`/定时任务`)。任务发送的目标会话 = 创建指令所在的会话(群聊即该群,私聊即该用户)。

| 指令 | 说明 |
|---|---|
| `/定时 添加 <时间> <消息1>\|<消息2>\|...` | 新建任务 |
| `/定时 列表` | 查看本会话任务 |
| `/定时 详情 <ID>` | 查看任务详情与轮换进度 |
| `/定时 消息 <ID> <消息1>\|<消息2>` | 替换任务的消息列表 |
| `/定时 时间 <ID> <时间>` | 修改任务的时间规则 |
| `/定时 启用 <ID>` / `/定时 停用 <ID>` | 启用 / 停用任务 |
| `/定时 测试 <ID>` | 立即按轮换顺序发送一条(不会删掉一次性任务) |
| `/定时 删除 <ID>` | 删除任务 |
| `/定时 全部` | (管理员)查看所有会话的任务 |
| `/定时 帮助` | 查看帮助 |

### 示例

```
/定时 添加 08:30 早安|早上好|good morning      # 每天 8:30,三条消息轮换
/定时 添加 周一三五@20:00 记得交日报
/定时 添加 每30分钟 该起来活动一下了
/定时 添加 cron 0 9 * * 1-5 工作日打卡提醒
/定时 添加 2026-10-01 09:00 国庆快乐!
/定时 消息 a1b2c3 新文案1|新文案2              # 更新消息
/定时 测试 a1b2c3                              # 立即发一条试试
```

ID 支持填写前缀(只要在任务中唯一)。

## 配置

在 WebUI 插件配置页修改(存于 `data/config/astrbot_plugin_scheduled_sender_config.json`):

| 配置项 | 默认 | 说明 |
|---|---|---|
| `timezone` | `Asia/Shanghai` | 任务时区(IANA 名称),无效时回退服务器本地时区 |
| `admin_only` | `false` | 仅管理员可管理定时任务 |
| `max_tasks_per_session` | `30` | 每个会话最大任务数 |
| `min_interval_seconds` | `60` | 间隔型任务最小间隔(防刷屏) |
| `misfire_grace_time` | `300` | 错过触发后的补发宽限秒数,0 表示不补发 |

## 注意事项

- 主动发消息依赖平台能力。用户也可以在 QQ 客户端关闭"接收机器人主动消息",关闭后发送一律失败。低频任务(如每天几条)一般没问题,高频任务(如每 N 分钟)在 QQ 官方平台容易被额度拦住,高频推送建议使用 aiocqhttp(NapCat/Lagrange)等协议端。
- 其余不支持主动发消息的平台(如有)上,任务会记录发送失败日志,不影响其他任务运行。
- 一条消息内如需换行,指令里不好输入,建议发送后用 `/定时 消息 <ID> ...` 更新(同样不支持多行);多条消息请用 `|` 分隔。
- 指令中 `|` 为消息分隔符,消息内容本身请勿包含 `|`。

## 数据文件

- 插件配置:`data/config/astrbot_plugin_scheduled_sender_config.json`
